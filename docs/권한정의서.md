## 3단계 관리자 권한

| 역할 | 대상 | 허용 범위 |
|---|---|---|
| **super_admin** (최고 관리자) | 발주기관 담당자 | 전체 + **매핑 재식별**(발주기관 전용) + 계정 관리 + 감사 로그 조회 |
| **admin** (일반 관리자) | 운영 담당자 | ETL·가명처리·발행 실행, 구독 관리, 대시보드·조회 |
| **viewer** (조회 사용자) | 현황 확인 인력 | 대시보드·대상자 조회(마스킹)만 |

## 엔드포인트별 권한 매트릭스

| 기능 | viewer | admin | super_admin |
|---|:-:|:-:|:-:|
| 대시보드 조회(/api/dashboard/*) | ○ | ○ | ○ |
| 대상자 조회 — 마스킹 적용(/api/data/*) | ○ | ○ | ○ |
| ETL·가명처리·발행 실행(/api/admin/etl, pseudonymize, publish) | × | ○ | ○ |
| 구독 등록·조회(/api/admin/subscriptions) | × | ○ | ○ |
| **매핑 재식별**(/api/admin/mappings/resolve) | × | × | ○ |
| 계정 관리(/api/admin/users) | × | × | ○ |
| 감사 로그(/api/admin/audit) | × | × | ○ |

## 화면 마스킹 규칙
- 이름: 가운데 마스킹(`김*희`), 연락처: 국번 마스킹(`010-****-5678`),
  주소: 읍·면·동까지만(`애월읍 (상세 비공개)`), 생년월일: 연령대로 대체.
- 자유기술(notes/memo)은 어떤 화면에도 노출하지 않는다.
- 마스킹은 **모든 역할의 화면에 공통 적용**된다. 원 식별자 확인이 필요한 발주기관
  업무는 재식별 API(super_admin, 전건 감사 기록)로만 수행한다.

## 계정·접근 통제(공통사항 라·마)
- 서버 접근 계정은 과업 수행 인력에게만 발급하고, 로그인·실행·재식별은 감사 로그에 기록된다.
- 매핑 테이블이 있는 운영 DB 계정은 발주기관 전용으로 분리한다.
